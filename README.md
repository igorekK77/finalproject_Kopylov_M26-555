# ValutaTrade Hub

**ValutaTrade Hub** - консольное приложение для управления виртуальным валютным портфелем. Позволяет регистрировать пользователей, покупать и продавать валюты, просматривать баланс и получать актуальные курсы фиатных и криптовалют.

## Установка и запуск

Для работы необходимы **Python 3.12+** и **uv**.

Клонируйте репозиторий:

```bash
git clone https://github.com/igorekK77/finalproject_Kopylov_M26-555.git
cd finalproject_Kopylov_M26-555
```

Установите зависимости:

```bash
uv sync
```

Запустите приложение:

```bash
uv run project
```

## Основные команды

| Команда | Описание                                 |
|---|------------------------------------------|
| `register` | Регистрация нового пользователя          |
| `login` | Авторизация пользователя                 |
| `show-portfolio` | Просмотр валютного портфеля              |
| `buy` | Покупка валюты                           |
| `sell` | Продажа валюты                           |
| `get-rate` | Получение курса валюты                   |
| `show-rates` | Просмотр курсов валют из локального кеша |
| `update-rates` | Обновление курсов валют                  |
| `help` | Справка по командам                      |
| `exit` | Завершение работы приложения             |

### Примеры использования

Получение курса валютной пары:

```bash
get-rate --from USD --to EUR
```

Просмотр всех доступных курсов:

```bash
show-rates
```

Просмотр курса конкретной валюты:

```bash
show-rates --currency BTC
```

Просмотр трёх самых дорогих криптовалют:

```bash
show-rates --top 3
```

Просмотр курсов относительно EUR:

```bash
show-rates --base EUR
```

Обновление всех курсов:

```bash
update-rates
```

Обновление курсов криптовалют:

```bash
update-rates --source coingecko
```


## Хранение данных

Данные приложения хранятся локально в формате JSON в каталоге `data/`.

- `users.json` — данные пользователей.
- `portfolios.json` — валютные портфели.
- `rates.json` — кеш актуальных курсов.
- `exchange_rates.json` — история изменения курсов.
- `config.json` — настройки приложения.

Для получения курсов используются внешние API: **CoinGecko** для криптовалют и **ExchangeRate-API** для фиатных валют.
